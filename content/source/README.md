# content/source — выгрузка действующего сайта cybermove.asia

Снято 2 октября 2026 г. со всех страниц действующего сайта. Это **источник текста**, а не файлы сайта: Astro их не читает, в сборку они не попадают.

## Состав

- `ru/**.md`, `en/**.md` — 176 страниц (88 + 88). Путь файла повторяет адрес: `ru/services/audit/business-audit.md` → `/services/audit/business-audit/`, `en/index.md` → `/en/`.
- `ru/_chrome.md`, `en/_chrome.md` — текст общего подвала.
- `pages.json` — все адреса с `<title>`.
- `images.json` — 100 изображений: `path` (адрес на cybermove.asia), `save_as` (имя без хеша), `alt` по языкам. Качаются скриптом `scripts/fetch-live-images.mjs`.

## Формат файла страницы

Шапка между `---`: `url`, `lang`, `title` (`<title>`), `description` (meta description), `h1`, `jsonld` (типы schema.org на странице).

Тело — текст `<main>` в порядке вёрстки, строка на блочный элемент:

| Запись | Значение |
|---|---|
| `# … ######` | заголовки h1–h6 |
| `- текст` | пункт списка |
| `текст {→/path/}` | ссылка: адрес стоит сразу после текста ссылки |
| `[img /_astro/… \| alt: …]` | изображение |
| `[field name (type)]`, `  option: …` | поле формы и варианты списка |
| ` \| ` внутри строки | граница между соседними строчными элементами (`<span>`): номер, название, описание, подпись. Это разделитель выгрузки, в текст сайта он не входит |

Особенности:

- Строки вида `01`, `01 / 04`, `01 · CORE`, `CAC · LTV · ROMI · CASH FLOW` — моноширинные метки и индексы блоков.
- В конце почти каждой страницы повторяется общий блок CTA («Начнём с первичного разбора…») — это компонент, не текст страницы.
- В начале `index.md` идёт текст интерактивной сцены и мега-меню (склеенные метки, списки направлений) — служебный шум; содержательная часть начинается с `# Приводим бизнес в движение…`. После блока формы там же продублирован подвал и меню.
- Имена, идущие подряд без пробелов (бегущая строка клиентов), в исходной вёрстке — отдельные элементы; ниже они продублированы списком.
- Текст передан дословно, включая неразрывные пробелы, кавычки-ёлочки и тире. Выгрузка сверена с сайтом по контрольным суммам.
