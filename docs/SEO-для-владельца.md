# SEO: что сделать владельцу

Сайт к поисковикам готовит Claude Code. Часть шагов можно сделать только из ваших аккаунтов — они ниже. Займёт около часа один раз и по 5 минут на каждую волну статей.

## 1. Google Search Console — подтвердить сайт

1. Откройте search.google.com/search-console под Google-аккаунтом компании (не личным, если есть общий).
2. «Добавить ресурс» → выберите **«Доменный ресурс»** и введите `cybermove.asia` (без https и www). Это лучший вариант: охватывает все адреса домена.
3. Google покажет TXT-запись вида `google-site-verification=…`. Скопируйте её.
4. В Plesk: «Сайты и домены» → cybermove.asia → «Настройки DNS» → «Добавить запись» → тип **TXT**, домен — пусто (корень), значение — скопированная строка → «ОК» → «Обновить».
   Если DNS домена ведёт не Plesk, а регистратор (например, ps.kz, hoster.kz) — та же запись добавляется в панели регистратора.
5. Вернитесь в Search Console и нажмите «Подтвердить». Если не прошло — подождите 1–24 часа (обновление DNS) и повторите.

Запасной способ (если с DNS не получается): «Ресурс с префиксом URL» → `https://cybermove.asia/` → способ «HTML-тег». Скопируйте код из `content="…"`, вставьте в файл `content/data/seo.json` в поле `googleSiteVerification`, попросите Claude Code пересобрать сайт и выложите. Затем «Подтвердить».

## 2. Отправить карту сайта

Search Console → «Файлы Sitemap» → введите `sitemap-index.xml` → «Отправить». Статус должен стать «Успешно». После каждой волны статей — нажать «Отправить» ещё раз.

Для пяти главных страниц (главная, услуги, кейсы, разборы, одна новая статья) — «Проверка URL» → вставить адрес → «Запросить индексирование».

## 3. Яндекс Вебмастер и Bing (рекомендуется для Казахстана)

- webmaster.yandex.ru → добавить сайт `https://cybermove.asia` → способ «Мета-тег» → код вставить в `seo.json` → поле `yandexVerification`. Там же отправить sitemap.
- Bing Webmaster Tools (bing.com/webmasters) → «Импорт из Google Search Console» — подтвердится автоматически.
- По желанию: ключ IndexNow (в Bing Webmaster) → в `seo.json` → `indexNowKey`; после каждой выкладки Claude Code запускает `npm run indexnow`.

## 4. Google Бизнес-профиль — сильнее всего влияет на запросы «… в Алматы»

business.google.com → создать профиль компании «Cyber Move Consulting», категория «Бизнес-консультант» / «Консультант по маркетингу», телефон +7 701 825 1028, сайт cybermove.asia, зона обслуживания — города Казахстана. Если офиса для приёма клиентов нет — указать «Выезжаю к клиентам», без адреса. Подтвердить (обычно видео или звонок). То же — в 2GIS. Затем пришлите ссылки на профили — их добавят на сайт и в разметку (`sameAs`).

## 5. Волны статей

Статьи публикуются четырьмя волнами: 8 октября, 20 октября, 2 ноября и 14 ноября 2026 года (даты — в `content/seo/waves.json` и в `REPORT.md`). Статья попадает на сайт, когда дата сборки ≥ её `publishDate`. В день волны:
1. Открыть проект в Claude Code и написать: «Собери сайт на сегодняшнюю дату и выложи» — или самому в терминале в папке проекта: `npm run deploy` (сборка + выкладка на cybermove.asia по FTPS).
2. Если задан ключ IndexNow — `npm run indexnow` (отправит в Bing и Яндекс только изменённые адреса).
3. В Search Console → «Файлы Sitemap» → «Отправить» ещё раз (`sitemap-index.xml`).

Почему волнами, а не сразу 88: резкий выброс большого числа новых статей Google может счесть массовой генерацией и понизить сайт целиком.

## 5а. Реальные авторы (усиливает доверие Google)

Сейчас автор всех разборов — «Редакция Cyber Move Consulting». Если эксперты компании готовы подписывать статьи своим именем: пришлите имя, должность, фото и ссылки на профили (LinkedIn и т. п.). Для каждого создаётся файл `src/content/authors/<slug>.md`, в статьях ставится `author: <slug>` — появится страница автора и разметка `Person`.

## 5б. Где лежат коды

Все коды подтверждения — в `content/data/seo.json`: `googleSiteVerification` (мета-тег), `googleHtmlFile` (имя и содержимое HTML-файла Google), `yandexVerification`, `bingVerification`, `indexNowKey`. Пустое значение — тег или файл не выводится. После правки — пересобрать и выложить (`npm run deploy`).

## 6. Чего ждать

- Первые показы в Search Console — через 1–3 недели после подтверждения.
- Устойчивые позиции по информационным запросам — обычно 3–6 месяцев; по коммерческим («консалтинг Алматы», «внедрение CRM Казахстан») — дольше и сильно зависят от отзывов, Бизнес-профиля и упоминаний компании на других сайтах.
- Первые места не гарантирует никто: это зависит от конкурентов и ссылок на сайт, а не только от текстов. Ускоряют: реальные авторы-эксперты с фото и именами, отзывы клиентов, публикации о компании в казахстанских СМИ и каталогах.
- Раз в месяц смотрите в Search Console «Эффективность»: какие запросы дают показы. Пришлите эти данные — по ним можно дописывать и усиливать статьи.
