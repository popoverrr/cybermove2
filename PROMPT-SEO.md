Если в Claude Code включён веб-поиск — оставьте включённым: он нужен для проверки фактов в статьях. Откройте папку в Claude Code и вставьте:

---

Сделай SEO-раздел по docs/16-seo.md: техническое SEO, подготовка к Google Search Console, 88 новых статей по плану content/seo/articles-plan.tsv (вместе с существующими — 100) и уникальные обложки к каждой в стиле сайта. Прочитай документ целиком до начала.

Порядок: сначала раздел A и B, сборка и проверка; затем генератор обложек и пилот — 3 статьи из разных рубрик целиком с обложками, проверь их по C.3–C.5 и посмотри обложки сам; затем остальные статьи пачками по рубрикам, после каждой пачки — npm run seo:check и редакторская вычитка 5 случайных статей.

Качество важнее объёма: каждая статья должна быть полезнее топа выдачи по своему запросу, без воды и шаблонных фраз. Факты о законах, госзакупках, налогах, тарифах и платформах — только с проверкой по первоисточнику через веб-поиск и ссылкой; не нашёл источник — не пиши конкретику и отметь статью в отчёте. Ничего не выдумывай: клиентов, цифры, цитаты, авторов, коды подтверждения.

Работай до конца без вопросов ко мне. В конце выполни «Приёмку», собери сайт на сегодняшнюю дату (опубликуется первая волна), закоммить и допиши раздел «SEO» в REPORT.md с датами волн.
